02 • THE RFMTC SIGNAL MATRIX

Four fundamental donor signals.

Every donor journey is codified by an adaptation of the RFM (Recency, Frequency, Monetary) behavioral model tailored specifically for healthcare analytics.

SIGNAL 01 • RECENCY (R)

Months Since Last Donation

The single strongest statistical predictor (r = -0.27). Return likelihood drops steeply after month 4.

08 • PROJECT ARCHITECTURE & PROVENANCE

Grounded in Capstone PRCP-1011.

Every coefficient, metric, and inference result in this application originates strictly from the Capstone Blood Donation Prediction dataset and notebook artifacts.

Dataset Provenance & Hygiene

  • 01 Source Center: Blood Transfusion Service Center in Hsin-Chu City, Taiwan (DrivenData benchmark).
  • 02 Data Deduplication: Initial 576 rows filtered of 153 identical donor entries, yielding 423 unique historical records.
  • 03 Stratified Split: 80% Training set (338 samples) and 20% Holdout Test set (85 samples), stratified on target variable.
  • 04 No Data Leakage: StandardScaler fitted strictly on the 338 training vectors and applied at inference.

Mathematical Formulation

1. FEATURE STANDARDIZATION
z = (x - μ) / σ
2. L2 EUCLIDEAN METRIC
d(x, x') = √ [ Σ (z_i - z'_i)² ]
3. CONSENSUS PROBABILITY
P(Y=1 | x) = (1 / k) · Σ I(y_neighbor = 1)
